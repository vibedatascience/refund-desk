# The claims

32 claims: 24 shown ("main") and 8 hidden. Each has a checked right answer in `labels.json`. They range from plain to hard: some need a better guide, some a tool, some a bigger model.

24 are few: the 95% interval is about +-18 points around the middle, so a step of two or three claims can be luck. 8 hidden claims are a smoke test, not a score.

A reviewer who saw only the rule book, the records and the photo decided each claim; all agree with the labels. The hard claims were picked because models differ on them, so this is a
teaching set, not a benchmark.
